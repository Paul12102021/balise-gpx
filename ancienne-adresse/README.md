# balise-gpx (ancienne adresse de Pisteo)

Pisteo est désormais sur https://pisteo.app/app/. Ce dépôt ne garde que la page de déménagement :
elle emporte les données des utilisateurs (sorties, traces, réglages) vers la nouvelle adresse,
et redirige les anciens liens (parcours partagés, retour Strava, confidentialité).
